# react-native-screen-gradient

React native screen-space gradient

## Installation


```sh
npm install react-native-screen-gradient
```


## Usage


```js
import { ScreenGradientView } from "react-native-screen-gradient";

// ...

<ScreenGradientView color="tomato" />
```
